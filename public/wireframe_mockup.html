PANDUAN IMPOR KE FIGMA

Kenapa tidak bisa langsung diimpor dari file lokal (file:///D:/...)?

Plugin Figma seperti HTML to Design berjalan di server cloud Figma. Server Figma tidak memiliki akses ke harddisk lokal Anda (file:///...) karena batasan keamanan browser (sandbox) dan jaringan.

Solusi Cara Impor:

  1. Metode Localhost (Direkomendasikan): Karena file ini diletakkan di folder public/wireframe_mockup.html, jalankan proyek Anda dengan perintah npm run dev. File ini akan bisa diakses melalui URL: http://localhost:5173/wireframe_mockup.html. Masukkan URL tersebut ke plugin Figma HTML to Design.
  2. Metode Chrome Extension: Install ekstensi Chrome HTML to Design di browser Anda. Buka file ini di browser, klik ikon ekstensi tersebut, lalu pilih unduh sebagai file .figma. Setelah terunduh, cukup drag-and-drop file tersebut langsung ke lembar kerja Figma Anda.
